Design System

bitnikgames design system

Tokens e componentes base extraídos de bitnikgames.vercel.app — CSS puro, sem dependências, para manter consistência visual entre projetos. Muda uma dúzia de variáveis em tokens.css e tens uma skin nova.

Abrir Skin Builder Ver no GitHub

Instalar

npm install git+https://github.com/dferreiramarques/bitnikgames-design-system.git
@import "@bitnikgames/design-system/src/index.css";

Sem npm? Copia a pasta src/ para o teu projeto. Ver README para instruções completas, incluindo como carregar as Google Fonts.
