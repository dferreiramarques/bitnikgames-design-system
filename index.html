Design System

bitnikgames design system

Tokens, componentes e padrões extraídos de bitnikgames.vercel.app — CSS puro, sem dependências, para manter consistência visual entre projetos. Muda uma dúzia de variáveis em tokens.css e tens uma skin nova.

Abrir Skin Builder UI de jogo Ver no GitHub

Instalar

npm install git+https://github.com/dferreiramarques/bitnikgames-design-system.git
@import "@bitnikgames/design-system/src/index.css";    /* tokens + base + componentes */
@import "@bitnikgames/design-system/src/patterns.css"; /* opcional: formulários, alertas, navegação… */
@import "@bitnikgames/design-system/src/game-ui.css";  /* opcional: cartas, chips, modais de jogo */

Sem npm? Copia a pasta src/ para o teu projeto. Instruções completas, incluindo as Google Fonts, no README.

Fundamentos

Tipografia

Baloo 2 para títulos e rótulos, Inter para texto corrido. As duas vêm das variáveis --font-display e --font-body.

Eyebrow

Título 1 — jogos pequenos

Título 2 — ideias grandes

Título 3 — catálogo e blog

Texto corrido em Inter: legível, neutro e com 1.6 de altura de linha. Cada jogo, cada ideia e cada nota de design cabem aqui sem esforço.

Texto secundário em .text-muted, para meta-informação e descrições.

Teclas e código: Ctrl + K e var(--brand-primary).

Acordeão

Quantas pessoas podem jogar?

Entre duas e seis, consoante o jogo. O número aparece em cada ficha do catálogo.

Posso jogar sem imprimir?

Sim, os jogos online abrem no browser e não precisam de instalação.

Há versões em inglês?

Todo o conteúdo existe sempre em português e inglês.

Passos e dicas

  1. Prepara a mesa

    Baralha as cartas e dá quatro a cada jogador.

  2. Joga por turnos

    Cada jogador escolhe uma carta e resolve o seu efeito.

  3. Conta os pontos

    Quem tiver mais capivaras no fim da ronda ganha.

Passa o rato ou foca 2–4 · 30 min para ver a dica.
